# Проект "Приложение для обработки вакансий"

## Описание:
Снтеграция с внешним сервисом HH.ru

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/WizardoftheSafretka/HHru_project.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

## Тестирование:
Для тестирования используется библиотека pytest.
Тесты стоит запускать командой  pytest из корневой директории проекта.
Тестовое покрытие составляет более 70%.


## Использование:
Запустите main.py
